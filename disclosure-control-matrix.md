# Disclosure Control Matrix

For every disclosure requirement maintain: Framework | Requirement ID | Topic | Applicability | Materiality conclusion | Evidence owner | Evidence link | Metric definition | Boundary | Period | Method | Assumptions | Estimate? | Comparative | Financial linkage | Draft disclosure | Reviewer | Status | Assurance evidence.

Statuses: Not assessed; Not applicable with rationale; Gap; In progress; Evidence ready; Drafted; Reviewed; Approved; Assured.

Never mark compliant solely because narrative exists. Evidence must support scope, period, methodology and quantitative claims.
